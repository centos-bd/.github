# Contributing to CentOS Kernel Community Bangladesh

Welcome! You don't need to be a kernel expert to contribute.

## Ways to contribute
- **Learn in public**: share notes, fix typos in guides
- **Workshops**: propose a talk, help organise, review slides
- **Code**: add example modules, eBPF tools, or improve existing ones
- **Mentor**: review a newcomer's patch

## First steps
1. Read our [Code of Conduct](../02-code-of-conduct.md)
2. Follow the [Kernel Learning Roadmap](../04-kernel-learning-roadmap.md) — pick your stage
3. Check open issues labelled `good first issue`

## Patch conventions
- Keep commits small and focused
- Write clear commit messages: `subsystem: short description`
- Run `checkpatch.pl` for kernel-related patches if applicable
- Be kind in reviews — explain the *why*

## Getting help
Ask in Discord `#help` — no question is too basic.
